# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to contact@insposcents.com. Do not include credentials, customer information, or exploit details in a public GitHub issue.

Please include the affected page or file, a concise description, reproduction steps, and the potential impact. Inspo Scents will acknowledge legitimate reports and prioritize fixes based on severity.

## Scope

The supported storefront is the Shopify theme deployed from the `main` branch. Shopify platform, checkout, and payment infrastructure issues should also be reported through Shopify's official security channels.

Never commit passwords, access tokens, API keys, customer data, payment data, or private certificates to this repository.
